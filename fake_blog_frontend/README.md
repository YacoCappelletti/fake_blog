# Fake Blog Frontend

React + TypeScript frontend for the Fake Blog Platform — a full-stack blogging app with Spring Boot backend.

## ✨ What this frontend does
- User authentication (login/register)
- Create, read, update, and delete blog posts
- Comment and reaction system
- Search and filter functionality
- Fully responsive UI built with Vite + React Router

## 🛠️ Tech Stack
React 18, TypeScript, Vite, React Router, CSS3.
