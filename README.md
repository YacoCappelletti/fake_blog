# Fake Blog Platform

A full-stack blogging platform built with React and Spring Boot.

## 🛠️ Tech Stack
- **Backend:** Java (Spring Boot, JPA) + Security
- **Frontend:** React.js + CSS3
- **Database:** MySQL (prod) / H2 (dev)
- **Build:** Maven

## ⚙️ What's inside
- Backend (`fake_blog_backend/`) handling REST API endpoints, JPA entities, and business logic.
- Frontend (`fake_blog_frontend/`) with reusable React components and responsive design.

## ✨ Features
- User authentication (register & login)
- Full CRUD for posts
- Comment and reaction system
- Search and filtering functionality
- Fully responsive layout

## ▶️ Running it locally
```bash
# Backend
cd fake_blog_backend && ./mvnw spring-boot:run

# Frontend
cd fake_blog_frontend && npm install && npm start
```
